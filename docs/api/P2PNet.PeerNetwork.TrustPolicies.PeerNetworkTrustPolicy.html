NetworkTaskTrustSettings

Configures the trust settings for executing network tasks within the peer-to-peer network.

public static NetworkTaskTrustConfiguration NetworkTaskTrustSettings { get; set; }

Property Value

NetworkTaskTrustConfiguration

Remarks

This static instance of NetworkTaskTrustConfiguration defines the trust parameters for each TaskType. It determines the conditions under which a network task is allowed to execute, such as requiring the sender to be a trusted peer or authority bootstrap server, or providing a valid signed hash. You can also mute a certain type of task using the parameter IgnoreAll or allow total pass through of all of a certain type with Open

The default configuration assigns specific trust requirements to certain task types. For example:

  • SendMessageDefaults to Open, allowing all peers to send messages.
  • BlockIPDefaults to requiring TrustedPeer and AuthorityBootstrapServer.
  • AssignIdentifierToPeerDefaults to requiring MustHaveSignedHash and AuthorityBootstrapServer.

For any TaskType not explicitly declared in the default configuration, trust requirements default to TrustedPeer and AuthorityBootstrapServer. This ensures that tasks not explicitly configured require some elevated trust by default (ie the sender of the task must be either a trust peer or an authority bootstrap server).

Users can modify this configuration at runtime to customize the trust requirements for specific task types. For example: 

PeerNetwork.TrustPolicies.PeerNetworkTrustPolicy.NetworkTaskTrustSettings.UpdateTrustParams(
    TaskType.SendMessage,
    TaskTrustParameter.TrustedPeer
);

SetIdentifier

Gets or sets the action responsible for automatically setting the peer network identifier based on system properties and network configuration.

public static Action SetIdentifier { get; set; }

Property Value

Action

Remarks

The default implementation, P2PNet.PeerNetwork.TrustPolicies.PeerNetworkTrustPolicy.SetIdentifierHandler(), generates the identifier by concatenating the system MAC address with the current date and time and computing an MD5 hash, then appending the public IP address (IPv6 if available, otherwise IPv4) and computing a second MD5 hash. The resulting hash is then assigned to the static Identifier property. This mechanism ensures that the identifier is unique and conforms to the policy specified by LocalIdentifierSetPolicy. Feel free to override this method with your own implementation.
