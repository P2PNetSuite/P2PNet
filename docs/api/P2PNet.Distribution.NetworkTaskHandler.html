Remarks

This static class maintains two concurrent queues—one for outgoing network tasks to be sent to trusted peers, and one for incoming network tasks that need to be processed. It uses timers to periodically check these queues and invoke appropriate handlers to process tasks based on their TaskType. Tasks may include actions such as blocking a peer, sending messages, pinging, and disconnecting peers.

The class also exposes a helper method to extract the PGP clear-signed signature from a network task, which is used for validation and verification purposes.
