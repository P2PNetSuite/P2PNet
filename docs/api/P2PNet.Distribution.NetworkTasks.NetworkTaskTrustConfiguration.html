Remarks

This class uses a dictionary mapping each TaskType to an array of allowed TaskTrustParameter values. The configuration can be initialized using a set of mapping entries provided via the params keyword.

For instance, you could initialize it like so: 

var config = new NetworkTaskTrustConfiguration(
    new TaskTrustMappingEntry(TaskType.SendMessage, TaskTrustParameter.Open),
    new TaskTrustMappingEntry(TaskType.BlockIP, TaskTrustParameter.TrustedPeer, TaskTrustParameter.AuthorityBootstrapServer),
    new TaskTrustMappingEntry(TaskType.UpdateSettings, TaskTrustParameter.MustHaveSignedHash)
);

Remarks

An array of TaskTrustMappingEntry values specifying the trust parameters for each task type.

For any TaskType not explicitly declared in the provided entries, default trust requirements of TrustedPeer and AuthorityBootstrapServer are assigned. This ensures that tasks not explicitly configured require elevated trust by default.
